# Deploy with GitHub Pages

1. Push the project to a public GitHub repository.
2. Open the repository settings.
3. Choose **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the root folder.
6. Save and wait for GitHub to publish the page.

Project links:

- Repository: https://github.com/QusayAlTaslaq/AlgoPath
- Website: https://qusayaltaslaq.github.io/AlgoPath/

After every update, open the website in a private browser window and check the
Console for errors.
